## decisions
- `signOut` is not merged with `features/auth` `switchAccount`. `signOut` calls `requireUser()` and sends a signed-out caller to `/sign-in` with no `next`; `switchAccount` works with an expired sign-in and keeps `next`. Merging means changing that guard and three form callers, so it is not a small change.
- `contracts/contour.json` keeps its `proposal` state kind; the gallery's state list draws it and the collector still uses it.
- The gallery's "Preview tools" flag (`NEXT_PUBLIC_PREVIEW_TOOLS`) is about preview deployments, not the removed shim, so it stays.
- Gallery sample text (`demo-v1`, `OBS-0244`) stays: the page is development-only and not indexed.
- `tests/auth.test.mjs` asserts the matcher by reading `proxy.ts` as text, because `proxy.ts` imports `next/server` and `@/` aliases that Node's type stripping cannot load.
